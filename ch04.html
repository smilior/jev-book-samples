手順1　緊急かどうか

Playground を開き、State に問い合わせ文、Questions に noul を1つ足して Run。

State に貼る文（緊急）

生ファイル

質問は書かない。材料だけ。

3日前からStripeアカウントが連携できなくて、売上が止まっています。至急対応してください。

Questions / noul の instructions

生ファイル

type=noul / ID=is_urgent。criteria は空でよい。

このメッセージは緊急性や時間的な切迫を伝えているか

手順2　急ぎではない文でもう1回

Questions はそのまま。State だけ差し替えて Run。

State に貼る文（急ぎではない）

生ファイル

noul が 0 に近づくはず。

今後の参考に、料金プランの一覧を送っていただけますか。急ぎではありません。

手順3　どの部署が見るべきか

3日前からStripeアカウントが連携できなくて、売上が止まっています。至急対応してください。

Questions / choice の instructions

どのチームが対応すべきか

Questions / choice の criteria

billing / technical / sales。
